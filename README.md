# tvorozhoc without a left arm

Клиентский мод для Minecraft **1.21.11** (Fabric).

## Возможности
- **Щит / тотем во второй руке**: положение (перетаскивание мышью или ползунки), размер и прозрачность.
- **Тотем**: можно отключить анимацию и звук срабатывания.
- **Остальное**:
  - свой цвет частиц тотема;
  - свой цвет частиц удара булавой;
  - свой звук удара булавой;
  - розовые ушки всем игрокам.

Настройки открываются клавишей **O** (меняется в управлении).

## Сборка
Нужен JDK 21.

```
./gradlew build
```

Готовый jar: `build/libs/`.
